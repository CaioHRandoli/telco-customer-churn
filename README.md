<h3>Data Science project using XGBoost, a machine learning algorithm to predict customer churn</h3>

This project was developed to classify and predict customer churn based on new data inputs (since losing a 
customer costs more than offering a retention incentive). I used Jupyter Notebook for the prototyping phase 
and Streamlit to create a web application where users can input new data, allowing the model to predict 
whether a customer has a low or high risk of churn.<br>
