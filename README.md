<h3>Data Science project using XGBoost (supervised learning), a machine learning model to predict customer churn</h3>

This project was developed to classify and predict customer churn based on new data inputs (since losing a 
customer costs more than offering a retention incentive). I used Jupyter Notebook for the prototyping phase, 
where the trained XGBoost model was exported, and this model was integrated into a streamlit web application
to deliver real-time predictions based on new user inputs, determining whether a customer has a low or high
risk of churn.<br>

<h3>🛠 Technologies and Technical Details</h3>

- **Programming Language**: Python
- **Environment**: Jupyter Notebook (Prototyping & Experimentation)
- **Machine Learning Model**: XGBoost (Classifier Algorithm)
- **Model Deployment**: Exported model integrated into Streamlit
- **Interface**: Streamlit (Web Application)
